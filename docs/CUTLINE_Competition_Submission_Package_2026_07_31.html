Devpost short description

CUTLINE is a human-governed release-assurance agent for agentic cinema. It investigates a failing VFX sequence through the official Grafana MCP, uses Gemini 2.5 Flash on Vertex AI to synthesize bounded evidence, proposes a deterministic recovery, requires operator approval, executes through Google Cloud, and verifies success with fresh telemetry and an auditable receipt.

What it does

Agentic cinema makes content creation faster, but it also creates a new production risk: many automated workers can fail together near a release deadline. CUTLINE answers the operational question that a creative team actually faces: “Will the final shots cross package lock, and can we prove a safe recovery?” The Eclipse Protocol demonstration starts with 18 final VFX shots, 4,800 frames of backlog, and 24 minutes until package lock. CUTLINE retrieves current Prometheus metrics and Loki logs through the official Grafana MCP runtime, correlates every item to one run, and asks Gemini 2.5 Flash to synthesize the evidence without giving the model authority over arithmetic, approval, execution, or verification. CUTLINE shows the root-cause hypothesis, alternative explanation, discriminator, falsifier, and deterministic deadline math. A human operator must approve the bounded recovery. Only then can the authenticated Google Cloud action execute. CUTLINE retrieves fresh post-action evidence and marks the run VERIFIED only when all six gates pass. The result includes an immutable receipt and complete audit lineage.

How we built it

CUTLINE is a Google ADK application deployed on Google Cloud Run. Gemini 2.5 Flash runs on Vertex AI and receives only a bounded evidence packet. A FastAPI workflow service owns state transitions, deterministic impact arithmetic, approval invariants, idempotency, receipts, and verification gates. The partner integration is the official grafana/mcp-grafana runtime, pinned by image digest and deployed as a private Cloud Run service with write tools disabled. CUTLINE authenticates to it with service identity, discovers Prometheus and Loki datasources, calls query_prometheus and query_loki_logs, and rejects missing, stale, malformed, or run-mismatched results. The only mutation path is an authenticated, allowlisted, idempotent Google Cloud action. Secrets are injected from Secret Manager and never exposed to the browser. Firestore provides durable action idempotency. The accessible web command center makes every evidence source, model boundary, operator decision, receipt, and verification gate visible.

Challenges, accomplishments, and learnings

Challenge

Agent demos often blur synthetic scenarios, model inference, provider evidence, and real actions. We designed CUTLINE so each boundary is explicit and fail-closed.

Accomplishment

A live end-to-end run changed failure rate from 120 to 320 frames/minute, cleared the OOM state, returned a Cloud Run receipt, and passed all six fresh-evidence gates.

Learning

The winning pattern is not maximum autonomy. It is visible evidence, narrow model authority, human control, bounded mutation, and proof after action.

Next

Add real studio pipeline connectors, multi-sequence release portfolios, role-based approvals, and historical risk calibration without weakening the evidence boundary.

Judging-criterion evidence

Technical Implementation

Production-hosted ADK/Gemini path, private official Grafana MCP runtime, service identity, deterministic workflow, authenticated action, fresh verification, 51 automated tests, and 100% statement/branch coverage.

Design

A media-native release command, accessible desktop/mobile UI, explicit evidence ledger, adversarial diagnosis, human approval card, receipt, verification report, and audit lineage.

Potential Impact

Agentic media scales output and operational risk together. CUTLINE is a reusable control plane for proving that automated production can meet deadlines without sacrificing human authority or auditability.

Quality of Idea

Rather than making another generative movie tool, CUTLINE addresses the neglected last mile: safely getting agent-created work across the release cutline.
