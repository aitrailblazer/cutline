Failure protocol

  1. Run the planned test without changing product code.
  2. Write the exact observed result and durable evidence path into the matching tracker row.
  3. Move failed rows to Failed Test; set severity and required fix.
  4. Fix only those tracker-backed failures and record files changed.
  5. Retest the row plus adjacent behavior; only then mark Verified.
